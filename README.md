# 📝 Gerenciador de Tarefas

Aplicação web de gerenciamento de tarefas desenvolvida com React.js e Firebase Firestore.

O projeto permite que usuários autenticados criem, visualizem, editem e excluam suas tarefas, com atualização dos dados em tempo real através do Firestore.

## 🚀 Demonstração

🔗 Repositório: https://github.com/Eduardo-pwbr/Eduardopwbr-Tarefas

A aplicação está em desenvolvimento e recebe melhorias contínuas.

## 📋 Funcionalidades

- ✅ Cadastro de tarefas
- ✏️ Edição de tarefas
- 🗑️ Exclusão de tarefas
- 👤 Associação das tarefas ao usuário autenticado
- 🔄 Atualização dos dados em tempo real
- 📅 Registro da data e hora de criação
- 🔐 Autenticação de usuários
- ☁️ Persistência dos dados no Firebase Firestore
- 📱 Interface responsiva
